# NetBox 소개

## 탄생 배경

NetBox는 2015년 [DigitalOcean](https://www.digitalocean.com/)에서 네트워크 엔지니어로 근무하던 수석 메인테이너 [Jeremy Stretch](https://github.com/jeremystretch)가 네트워크 프로비저닝 자동화의 일환으로 개발했습니다. 이 새로운 도구의 잠재력을 인식한 DigitalOcean은 2016년 6월에 오픈소스 프로젝트로 공개하는 데 동의했습니다.

이후 전 세계 수천 개의 조직이 NetBox를 네트워크 운영자와 자동화를 지원하는 중앙 네트워크 신뢰 소스(source of truth)로 채택했습니다. 현재 이 오픈소스 프로젝트는 [NetBox Labs](https://netboxlabs.com/)와 자원봉사 메인테이너 팀이 관리하고 있습니다. 핵심 제품 외에도 NetBox 커뮤니티에서 기능을 강화하고 확장하는 수많은 [플러그인](https://netbox.dev/plugins/)을 개발했습니다.

## 주요 기능

NetBox는 네트워크 엔지니어와 운영자의 요구사항을 충족하기 위해 특별히 제작되었습니다. 아래는 NetBox가 제공하는 핵심 기능에 대한 간략한 개요입니다.

* 완전한 IPv4/IPv6 지원을 갖춘 IP 주소 관리(IPAM)
* 다음 사용 가능한 프리픽스/IP 자동 프로비저닝
* 임포트 및 익스포트 라우트 타겟을 포함한 VRF
* 가변 범위 그룹을 지원하는 VLAN
* AS 번호(ASN) 관리
* SVG 렌더링을 지원하는 랙 엘리베이션
* 사전 정의된 타입을 사용한 장비 모델링
* 가상 섀시 및 장비 컨텍스트
* SVG 추적을 지원하는 네트워크, 전원, 콘솔 케이블링
* 브레이크아웃 케이블
* 전력 분배 모델링
* 데이터 회선 및 제공업체 추적
* 무선 LAN 및 포인트-투-포인트 링크
* VPN 터널
* IKE 및 IPSec 정책
* 레이어 2 VPN 오버레이
* FHRP 그룹 (VRRP, HSRP 등)
* 애플리케이션 서비스 바인딩
* 가상 머신 및 클러스터
* 사이트 및 로케이션을 위한 유연한 계층 구조
* 테넌트 소유권 할당
* 고급 구성 렌더링을 위한 장비 및 VM 구성 컨텍스트
* 데이터 모델 확장을 위한 커스텀 필드
* 커스텀 유효성 검사 및 보호 규칙
* UI에서 직접 실행 가능한 커스텀 리포트 및 스크립트
* 커스텀 기능 추가를 위한 광범위한 플러그인 프레임워크
* 싱글 사인온(SSO) 인증
* 강력한 객체 기반 권한
* 상세한 자동 변경 로깅
* 글로벌 검색 엔진
* 이벤트 기반 스크립트 및 웹훅

## NetBox가 아닌 것

NetBox는 네트워크 관리의 많은 영역을 다루고자 하지만, 기능 범위는 필연적으로 제한됩니다. 이를 통해 개발이 핵심 기능에 집중되고 범위 확장이 합리적으로 억제됩니다. 이를 위해 NetBox가 제공하지 **않는** 기능의 몇 가지 예를 들면:

* 네트워크 모니터링
* DNS 서버
* RADIUS 서버
* 구성 관리
* 시설 관리

그러나 NetBox는 이러한 기능을 수행하는 외부 도구에 필요한 데이터를 채우는 데 매우 효과적으로 사용될 수 있습니다.

## 설계 철학

NetBox는 다음 원칙을 최우선으로 고려하여 설계되었습니다.

### 실제 세계 복제

데이터 모델이 실제 네트워크를 정확하게 반영할 수 있도록 신중하게 고려했습니다. 예를 들어, IP 주소는 장비가 아닌 장비에 연결된 특정 인터페이스에 할당되며, 하나의 인터페이스에 여러 IP 주소가 할당될 수 있습니다.

### "신뢰 소스(Source of Truth)" 역할

NetBox는 네트워크의 _운영_ 상태가 아닌 _희망_ 상태를 나타내고자 합니다. 따라서 라이브 네트워크 상태의 자동 가져오기는 강력히 권장하지 않습니다. NetBox에서 생성되는 모든 데이터는 먼저 무결성을 보장하기 위해 사람이 검증해야 합니다. 그런 다음 NetBox를 사용하여 높은 신뢰도로 모니터링 및 프로비저닝 시스템을 채울 수 있습니다.

### 단순함 유지

상대적으로 간단한 [80% 솔루션](https://en.wikipedia.org/wiki/Pareto_principle)과 훨씬 더 복잡한 완전한 솔루션 중에서 선택해야 할 경우, 일반적으로 전자가 선호됩니다. 이를 통해 학습 곡선이 낮은 간결한 코드베이스를 보장합니다.

## 애플리케이션 스택

NetBox는 [Django](https://djangoproject.com/) Python 프레임워크를 기반으로 구축되었으며 [PostgreSQL](https://www.postgresql.org/) 데이터베이스를 사용합니다. 선택한 HTTP 서버 뒤에서 WSGI 서비스로 실행됩니다.

| 기능              | 컴포넌트           |
|-------------------|-------------------|
| HTTP 서비스       | nginx 또는 Apache |
| WSGI 서비스       | gunicorn 또는 uWSGI |
| 애플리케이션      | Django/Python     |
| 데이터베이스      | PostgreSQL 14+    |
| 태스크 큐잉       | Redis/django-rq   |
