# 데이터 채우기

이 섹션에서는 NetBox에 데이터를 채우는 데 사용할 수 있는 메커니즘을 다룹니다.

## 수동 객체 생성

NetBox에 데이터를 채우는 가장 간단하고 직접적인 방법은 사용자 인터페이스의 객체 생성 폼을 사용하는 것입니다.

!!! warning "대량 가져오기에는 적합하지 않음"
    초보 사용자도 편리하게 쉽게 접근할 수 있지만, 이러한 폼을 수동으로 작성하여 한 번에 하나씩 객체를 생성하는 것은 확장성이 좋지 않습니다. 대량 가져오기의 경우 일반적으로 이 섹션에서 설명하는 다른 방법 중 하나를 사용하는 것이 좋습니다.

NetBox에서 새 객체를 생성하려면 탐색 메뉴에서 객체 타입을 찾고 녹색 "추가" 버튼을 클릭하세요.

!!! info "버튼이 없나요?"
    특정 객체 타입에 대해 "추가" 버튼이 보이지 않는다면, 계정에 이러한 타입을 생성할 충분한 권한이 없을 가능성이 높습니다. NetBox 관리자에게 필요한 권한을 부여해 달라고 요청하세요.

    또한 장비 컴포넌트와 같은 일부 객체 타입은 탐색 메뉴에서 직접 생성할 수 없다는 점에 유의하세요. 이러한 객체는 상위 객체(예: 상위 장비)의 컨텍스트 내에서 생성해야 합니다.

## 대량 가져오기 (CSV/YAML)

NetBox는 CSV 형식의 데이터를 사용하여 새 객체의 대량 가져오기 및 기존 객체 업데이트를 지원합니다. 이 방법은 CSV 데이터로 변환하기 매우 쉬운 스프레드시트 데이터를 가져오는 데 이상적입니다. CSV 데이터는 폼 필드를 사용하여 원시 텍스트로 가져오거나 적절히 형식화된 CSV 파일을 업로드하여 가져올 수 있습니다.

객체 타입에 대한 CSV 가져오기 폼을 볼 때, 필수 열의 헤더가 미리 채워져 있는 것을 알 수 있습니다. 각 폼에는 참조용으로 지원되는 _모든_ 열을 나열하는 "CSV 필드 옵션"이라는 제목의 테이블이 있습니다. (일반적으로 이것들은 개별 객체에 대한 해당 생성 폼에서 볼 수 있는 필드에 매핑됩니다.)

"id" 필드가 추가되면 데이터는 새 객체를 가져오는 대신 기존 레코드를 업데이트하는 데 사용됩니다.

일부 모델(즉, 장비 타입 및 모듈 타입)은 CSV 가져오기를 지원하지 않습니다. 대신 상위 객체와 하위 컴포넌트 모두의 가져오기를 용이하게 하기 위해 YAML 형식의 데이터를 허용합니다.

## 스크립팅

때로는 NetBox에 채워야 할 데이터가 패턴으로 쉽게 축소될 수 있습니다. 예를 들어, 100개의 지점 사이트가 있고 각 사이트에 101부터 105까지 번호가 매겨진 5개의 VLAN이 있다고 가정합니다. 가져오기를 위해 CSV 파일에 이 500개의 VLAN을 각각 명시적으로 정의하는 것도 물론 가능하지만, 패턴에 따라 이러한 VLAN을 자동으로 생성하는 간단한 커스텀 스크립트를 작성하는 것이 더 빠를 수 있습니다. 스크립트가 여기저기서 VLAN을 "놓치는" 것이 불가능하므로 데이터의 유효성에 대해 높은 신뢰도를 보장합니다.

!!! tip "스크립트로 기존 데이터 재구성"
    때로는 가져오기에 필요한 데이터가 준비되어 있더라도 객체를 채우기 위해 스크립트를 작성하고 싶을 수 있습니다. 스크립트를 사용하면 가져오기 전에 기존 데이터를 수동으로 검증할 필요가 없기 때문입니다.

## REST API

REST API를 사용하여 NetBox에 데이터를 채울 수도 있습니다. REST API는 UI 폼에서 적용되는 동일한 검증 규칙에 따라 객체 생성에 대한 완전한 프로그래밍 방식의 제어를 제공합니다. 또한 REST API는 단일 요청을 사용하여 여러 객체의 대량 생성을 지원합니다.

이 옵션에 대한 자세한 내용은 [REST API 문서](../integrations/rest-api.md)를 참조하세요.
