# 변경 로깅

NetBox에서 객체가 생성, 업데이트 또는 삭제될 때마다 변경 전후에 해당 객체의 직렬화된 복사본이 현재 시간과 변경과 관련된 사용자를 포함한 메타데이터와 함께 데이터베이스에 저장됩니다. 이러한 레코드는 각 개별 객체와 NetBox 전체에 대한 영구적인 변경 기록을 형성합니다. 전역 변경 로그는 Other > Change Log로 이동하여 볼 수 있습니다.

수정 중인 인스턴스의 직렬화된 표현이 JSON 형식으로 포함됩니다. 이는 REST API 내에서 객체가 전달되는 방식과 유사하지만 중첩된 표현은 포함하지 않습니다. 예를 들어 사이트의 `tenant` 필드는 테넌트 표현이 아닌 테넌트의 ID만 기록합니다.

요청이 이루어지면 UUID가 생성되어 해당 요청으로 인한 모든 변경 레코드에 첨부됩니다. 예를 들어 세 개의 객체를 일괄 편집하면 각각에 대해 별도의 변경 레코드가 생성되고(총 세 개), 각 객체는 동일한 UUID와 연결됩니다. 이렇게 하면 특정 요청으로 인한 모든 변경 레코드를 쉽게 식별할 수 있습니다.

변경 레코드는 읽기 전용 엔드포인트 `/api/extras/object-changes/`를 통해 API에서 노출됩니다. 웹 UI를 통해 CSV 형식으로 내보낼 수도 있습니다.

## 사용자 메시지

!!! info "이 기능은 NetBox v4.4에서 도입되었습니다."

NetBox에서 객체를 생성, 수정 또는 삭제할 때 사용자는 변경 레코드에 나타날 임의의 메시지를 기록할 수 있습니다. 이는 변경 이유와 같은 추가 컨텍스트를 캡처하는 데 유용할 수 있습니다.

## 요청별 변경 상관관계

NetBox에 대한 모든 요청에는 변경 레코드를 상관시키는 데 사용할 수 있는 무작위 고유 ID가 할당됩니다. 예를 들어 UI의 일괄 편집 기능을 사용하여 세 개의 사이트 상태를 변경하면 모두 동일한 요청 ID를 참조하는 세 개의 새 변경 레코드(각 사이트에 대해 하나씩)가 표시됩니다. 이는 세 가지 변경이 모두 동일한 요청의 일부로 이루어졌음을 보여줍니다.
