# 사용자 기본 설정

NetBox는 웹 인터페이스 및 데이터 표시의 측면을 제어하는 사용자별 옵션을 저장합니다. 기본 설정은 세션 간에 유지되며 **User → Preferences**에서 관리할 수 있습니다.

## 테이블 구성

**Configure**를 사용하여 목록 보기를 구성하면 NetBox는 선택한 열과 순서를 해당 테이블에 대한 사용자별 테이블 기본 설정으로 기록합니다. 이러한 기본 설정은 이후 방문 시 자동으로 적용됩니다.

### 테이블 기본 설정 지우기

예를 들어 테이블이 렌더링되지 않거나 사용 가능한 열을 변경하는 업그레이드 후에 저장된 테이블 기본 설정을 재설정해야 할 수 있습니다.

하나 이상의 테이블에 대해 저장된 기본 설정을 지우려면:

1. 오른쪽 상단 모서리에서 사용자 이름을 클릭합니다.
2. 드롭다운에서 **Preferences**를 선택합니다.
3. **Table Configurations** 섹션으로 스크롤합니다.
4. 재설정할 테이블을 선택합니다.
5. **Submit**을 클릭하여 선택한 기본 설정을 지웁니다.

기본 설정을 지운 후 목록 보기를 다시 열고 **Configure**를 사용하여 원하는 열과 순서를 설정합니다.

!!! note
    사용자별 테이블 기본 설정은 *Customization → Table Configs*에서 관리되는 명명된 재사용 가능한 구성인 **Table Configs**와 다릅니다. 기본 설정을 지워도 Table Configs는 삭제되지 않습니다. 자세한 내용은 [Table Configs](../models/extras/tableconfig.md)를 참조하세요.

## 기타 기본 설정

### 언어
설치된 번역에서 사용자 인터페이스 언어를 선택합니다(시스템 구성에 따름).

### 페이지 길이
페이지가 매겨진 테이블에 표시되는 기본 행 수를 설정합니다.

### 페이지네이터 위치
테이블에 대해 페이지네이션 컨트롤이 렌더링되는 위치를 제어합니다.

### HTMX 탐색(실험적)
지원되는 보기에 대해 부분 페이지 탐색을 활성화합니다. 예기치 않은 동작이 관찰되면 이 기본 설정을 비활성화하세요.

### 줄무늬 테이블 행
테이블에서 교대 행 배경을 전환합니다.

### 데이터 형식(원시 보기)
원시 데이터 블록을 렌더링할 때 기본 형식(JSON 또는 YAML)을 설정합니다.

### CSV 구분 기호
CSV 데이터를 내보낼 때 사용되는 구분 기호를 재정의합니다.

## 북마크

사용자는 편리한 접근을 위해 자주 방문하는 객체를 북마크할 수 있습니다. 북마크는 사용자 메뉴 아래에 나타나며 북마크 위젯을 사용하여 개인 대시보드에 표시할 수 있습니다. 모델 세부 정보는 [Bookmark](../models/extras/bookmark.md)를 참조하세요.

## 알림 및 구독

사용자는 객체를 구독하여 변경 사항이 발생할 때 알림을 받을 수 있습니다. 알림은 사용자 메뉴 아래에 나열되며 읽음으로 표시하거나 삭제할 수 있습니다. [기능 > 알림](notifications.md) 및 [Subscription](../models/extras/subscription.md)과 [Notification](../models/extras/notification.md)에 대한 데이터 모델 참조를 확인하세요.

## 관리자 기본값

관리자는 [`DEFAULT_USER_PREFERENCES`](../configuration/default-values.md#default_user_preferences)를 통해 새 사용자에 대한 기본값을 정의할 수 있습니다. 사용자는 자신의 기본 설정에서 이러한 값을 재정의할 수 있습니다.
