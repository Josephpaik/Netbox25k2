# 백그라운드 작업

NetBox에는 특정 기능을 백그라운드 작업으로 실행하는 기능이 포함되어 있습니다. 여기에는 다음이 포함됩니다:

* [사용자 정의 스크립트](../customization/custom-scripts.md) 실행
* [원격 데이터 소스](../integrations/synchronized-data.md) 동기화
* 하우스키핑 작업

또한 NetBox 플러그인은 자체 백그라운드 작업을 대기열에 넣을 수 있습니다. 이는 [Job 모델](../models/core/job.md)을 사용하여 수행됩니다. 백그라운드 작업은 `rqworker` 프로세스에 의해 실행됩니다.

## 예약된 작업

백그라운드 작업은 즉시 실행되거나 미래의 정해진 시간에 실행되도록 구성할 수 있습니다. 예약된 작업은 정해진 간격으로 반복되도록 구성할 수도 있습니다.
