# 검색

## 전역 검색

NetBox에는 복잡한 데이터 모델 전체를 검색할 수 있는 단일 편리한 인터페이스를 제공하는 강력한 전역 검색 엔진이 포함되어 있습니다. 각 모델의 관련 필드는 우선순위에 따라 인덱싱되어 가장 관련성 높은 결과가 먼저 반환됩니다. 객체가 생성되거나 수정되면 검색 인덱스가 즉시 업데이트되어 실시간 정확성을 보장합니다.

검색 쿼리를 입력할 때 사용자는 정확한 일치, 부분 일치 등 특정 조회 유형을 선택할 수 있습니다. 부분 일치가 발견되면 해당 필드 값의 일치하는 부분이 각 결과에 포함되어 사용자가 관련성을 쉽게 판단할 수 있습니다.

NetBox 관리자가 정의한 사용자 정의 필드도 검색 가중치가 구성된 경우 검색 결과에 포함됩니다. 또한 NetBox 플러그인은 핵심 모델과 함께 포함되도록 자체 사용자 정의 모델을 등록할 수 있습니다.

!!! note
    NetBox는 정적 선택 필드(사용자 정의 필드의 "Selection" 또는 "Multiple selection" 유형 포함)를 인덱싱하지 않습니다.

## 저장된 필터

NetBox의 각 객체 유형에는 특정 속성에 연결된 광범위한 필터 세트가 함께 제공되어 복잡한 쿼리를 생성할 수 있습니다. 종종 특정 쿼리가 쿼리에 일부 규정된 조건 집합을 적용하기 위해 일상적으로 사용되는 것을 발견할 것입니다. 필터 세트가 적용되면 NetBox는 나중에 사용할 수 있도록 저장하는 옵션을 제공합니다.

예를 들어 지역 내의 특정 유형의 모든 계획된 장비를 자주 찾아야 한다고 가정합니다. 적용 가능한 필터를 적용하고 재사용을 위해 사용자 정의 명명된 필터로 저장할 수 있습니다:

```
?status=planned&device_type_id=78&region_id=12
```

다음과 같이 됩니다:

```
?filter=my-custom-filter
```

이러한 저장된 필터는 UI 및 API 쿼리 모두에서 사용할 수 있습니다.
