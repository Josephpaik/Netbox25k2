# 동기화된 데이터

NetBox의 여러 모델은 지정된 원격 소스에서 로컬 데이터의 자동 동기화를 지원합니다. 예를 들어 NetBox에 정의된 [구성 템플릿](./configuration-rendering.md)은 원격 git 저장소에 저장된 텍스트 파일에서 콘텐츠를 가져올 수 있습니다. 이는 코어 [데이터 소스](../models/core/datasource.md) 및 [데이터 파일](../models/core/datafile.md) 모델을 사용하여 수행됩니다.

원격 데이터 동기화를 활성화하려면 NetBox 관리자가 먼저 하나 이상의 원격 데이터 소스를 지정합니다. NetBox는 현재 다음 소스 유형을 지원합니다:

* Git 저장소
* Amazon S3 버킷(또는 호환 제품)
* 로컬 디스크 경로

(로컬 디스크 경로는 NetBox의 데이터베이스 외부에 존재하므로 이 컨텍스트에서 "원격"으로 간주됩니다. 이러한 경로는 외부 네트워크 공유에도 매핑될 수 있습니다.)

!!! info
    외부 소스에 연결하는 데이터 백엔드는 일반적으로 하나 이상의 지원 Python 라이브러리 설치가 필요합니다. Git 백엔드에는 [`dulwich`](https://www.dulwich.io/) 패키지가 필요하고, S3 백엔드에는 [`boto3`](https://boto3.amazonaws.com/v1/documentation/api/latest/index.html) 패키지가 필요합니다. 이러한 백엔드를 활성화하려면 NetBox 환경 내에 설치해야 합니다.

!!! info
    Git을 구성하고 SOCKS 프로토콜을 사용하도록 `HTTP_PROXIES`를 구성한 경우 [`python_socks`](https://pypi.org/project/python-socks/) Python 라이브러리도 설치해야 합니다.

각 유형의 원격 소스에는 고유한 구성 매개변수가 있습니다. 예를 들어 git 소스는 사용자에게 브랜치 및 인증 자격 증명을 지정하도록 요청합니다. 소스가 생성되면 동기화 작업이 실행되어 원격 파일을 로컬 데이터베이스에 자동으로 복제합니다.

다음 NetBox 모델은 복제된 데이터 파일과 연결할 수 있습니다:

* 구성 컨텍스트
* 구성 템플릿
* 내보내기 템플릿

로컬 인스턴스에 데이터가 지정되면 해당 데이터는 복제된 파일의 콘텐츠로 교체됩니다. 복제된 파일이 미래에 업데이트되면(동기화 작업을 통해) 로컬 인스턴스는 오래된 데이터가 있는 것으로 플래그 지정됩니다. 그런 다음 사용자는 이러한 객체를 개별적으로 또는 대량으로 동기화하여 업데이트를 적용할 수 있습니다. 이 2단계 프로세스는 자동화된 동기화 작업이 프로덕션 데이터에 즉시 영향을 미치지 않도록 보장합니다.

!!! note "권한"
    사용자가 원격 데이터 소스에서 로컬 파일을 동기화하려면 `core.sync_datasource` 권한이 할당되어야 합니다.
