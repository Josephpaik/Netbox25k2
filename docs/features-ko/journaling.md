# 저널링

NetBox의 모든 기본 및 조직 모델은 저널링을 지원합니다. 저널은 역사적 컨텍스트를 위해 유지되는 객체에 대한 사람이 생성한 메모와 코멘트의 모음입니다. 이는 NetBox의 변경 로그를 보완하여 변경이 이루어진 이유 또는 NetBox 외부에서 발생하는 이벤트를 전달하기 위한 추가 정보를 제공합니다. 레코드가 일반적으로 구성 가능한 기간 후에 만료되는 변경 로그와 달리 저널 항목은 연결된 객체의 수명 동안 지속됩니다.

각 저널 항목에는 선택 가능한 종류(정보, 성공, 경고 또는 위험)와 사용자가 입력하는 `comments` 필드가 있습니다. 각 항목은 생성 시 자동으로 날짜, 시간 및 관련 사용자를 기록합니다.
