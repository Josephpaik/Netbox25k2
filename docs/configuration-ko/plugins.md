# 플러그인 매개변수

## PLUGINS

기본값: `[]`

활성화할 설치된 [NetBox 플러그인](../plugins/index.md) 목록입니다. 플러그인은 여기에 나열되지 않으면 적용되지 않습니다.

!!! warning
    플러그인은 NetBox 자체와 동일한 접근 권한 및 권한으로 외부 코드를 실행하여 NetBox를 확장합니다. 신뢰할 수 있는 소스의 플러그인만 설치하세요. NetBox 관리자는 플러그인이 활성화된 설치의 무결성이나 보안에 대해 어떠한 보증도 하지 않습니다.

---

## PLUGINS_CONFIG

기본값: `[]`

이 매개변수는 개별 NetBox 플러그인에 대한 구성 설정을 보유합니다. 각 키가 설치된 플러그인의 이름을 사용하는 딕셔너리로 정의됩니다. 지원되는 특정 매개변수는 각 플러그인마다 다릅니다: 지원되는 매개변수를 확인하려면 플러그인의 문서를 참조하세요. 예제 구성은 다음과 같습니다:

```python
PLUGINS_CONFIG = {
    'plugin1': {
        'foo': 123,
        'bar': True
    },
    'plugin2': {
        'foo': 456,
    },
}
```

플러그인의 구성이 적용되려면 `PLUGINS`에 나열되어 있어야 합니다.

---

## PLUGINS_CATALOG_CONFIG

기본값: `{}` (비어 있음)

이 매개변수는 Admin > System > Plugins 아래의 플러그인 카탈로그에 개별 플러그인이 표시되는 방식을 제어합니다. `hidden` 목록에 플러그인을 추가하면 해당 플러그인이 카탈로그에서 생략됩니다. `static` 목록에 플러그인을 추가하면 플러그인이 표시되지만 플러그인 세부 정보나 업그레이드 지침에 연결되지 않습니다.

예제 구성은 다음과 같습니다:

```python
PLUGINS_CATALOG_CONFIG = {
    'hidden': [
        'plugin1',
    ],
    'static': [
        'plugin2',
    ],
}
```
