# 개발 매개변수

## DEBUG

기본값: `False`

이 설정은 디버깅을 활성화합니다. 디버깅은 개발 또는 문제 해결 중에만 활성화해야 합니다. 인식된 [내부 IP 주소](./system.md#internal_ips)에서 NetBox에 접근하는 클라이언트만 사용자 인터페이스에서 디버깅 도구를 볼 수 있습니다.

!!! warning
    프로덕션 시스템에서는 절대 디버깅을 활성화하지 마세요. 인증되지 않은 사용자에게 민감한 데이터가 노출되고 상당한 성능 저하가 발생할 수 있습니다.

---

## DEVELOPER

기본값: `False`

이 매개변수는 새 데이터베이스 스키마 마이그레이션 생성과 같은 잠재적으로 위험한 동작을 방지하는 안전 장치 역할을 합니다. 또한 이 설정을 활성화하면 UI에서 디버그 경고 배너가 비활성화됩니다. NetBox 코드 베이스를 적극적으로 개발하는 경우에**만** 이것을 `True`로 설정하세요.
