# 사용자 정의 필드

NetBox의 각 모델은 데이터베이스에서 개별 테이블로 표현되며, 모델의 각 속성은 테이블 내에 열로 존재합니다. 예를 들어, 사이트는 `dcim_site` 테이블에 저장되며, 이 테이블에는 `name`, `facility`, `physical_address` 등의 열이 있습니다. NetBox 개발 과정에서 객체에 새 속성이 추가되면 테이블이 확장되어 새 행을 포함합니다.

그러나 일부 사용자는 다소 난해한 성격의 추가 객체 속성을 저장하고 싶어할 수 있으며, 이러한 속성은 핵심 NetBox 데이터베이스 스키마에 포함하는 것이 적합하지 않습니다. 예를 들어, 조직에서 각 장비를 내부 지원 시스템 레코드와 연관시키는 티켓 번호와 연결해야 한다고 가정해 보겠습니다. 이것은 확실히 NetBox의 합법적인 사용이지만 _모든_ NetBox 설치에 대해 필드를 포함할 만큼 일반적인 필요는 아닙니다. 대신 이 데이터를 보관할 사용자 정의 필드를 만들 수 있습니다.

데이터베이스 내에서 사용자 정의 필드는 각 객체와 함께 JSON 데이터로 직접 저장됩니다. 이렇게 하면 객체를 검색할 때 복잡한 쿼리가 필요하지 않습니다.

## 사용자 정의 필드 만들기

사용자 정의 필드는 Customization > Custom Fields로 이동하여 만들 수 있습니다. NetBox는 여러 유형의 사용자 정의 필드를 지원합니다:

* Text: 자유 형식 텍스트(한 줄 사용 목적)
* Long text: 모든 길이의 자유 형식 텍스트; Markdown 렌더링 지원
* Integer: 정수(양수 또는 음수)
* Decimal: 고정 정밀도 소수(소수점 4자리)
* Boolean: True 또는 False
* Date: ISO 8601 형식의 날짜(YYYY-MM-DD)
* Date & time: ISO 8601 형식의 날짜 및 시간(YYYY-MM-DD HH:MM:SS)
* URL: 웹 UI에서 링크로 표시됨
* JSON: JSON 형식으로 저장된 임의 데이터
* Selection: 여러 사전 정의된 사용자 정의 선택 항목 중 하나 선택
* Multiple selection: 여러 값의 할당을 지원하는 선택 필드
* Object: `object_type`으로 정의된 유형의 단일 NetBox 객체
* Multiple object: `object_type`으로 정의된 유형의 하나 이상의 NetBox 객체

각 사용자 정의 필드에는 이름이 있어야 합니다. 이것은 간단한 데이터베이스 친화적인 문자열(예: `tps_report`)이어야 하며 영숫자 문자와 밑줄만 포함할 수 있습니다. 해당하는 사용자 친화적인 레이블(예: "TPS report")을 할당할 수도 있습니다. 레이블은 웹 양식에 표시됩니다. 가중치도 필요합니다: 높은 가중치 필드는 양식 내에서 아래로 정렬됩니다. (기본 가중치는 100입니다.) 설명이 제공되면 양식의 필드 아래에 표시됩니다.

필드를 필수로 표시하면 새 객체를 만들거나 기존 객체를 저장할 때 사용자가 필드에 대한 값을 제공하도록 강제합니다. 필드에 대한 기본값도 제공할 수 있습니다. 부울 필드에는 "true" 또는 "false"를 사용하고, 선택 필드에는 선택 항목의 정확한 값을 사용합니다.

사용자 정의 필드는 NetBox의 하나 이상의 객체 유형 또는 모델에 할당해야 합니다. 생성되면 사용자 정의 필드가 웹 UI 및 REST API에서 이러한 모델의 일부로 자동으로 표시됩니다. 모든 모델이 사용자 정의 필드를 지원하는 것은 아닙니다.

### 필터링

필터 로직은 사용자 정의 필드로 객체를 필터링할 때 값이 일치하는 방식을 제어합니다. 느슨한 필터링(기본값)은 부분 값과 일치하는 반면 정확한 일치는 주어진 문자열과 필드 값의 완전한 일치가 필요합니다. 예를 들어, "red" 문자열로 정확한 필터링은 정확한 값 "red"만 일치시키는 반면, 느슨한 필터링은 "red", "red-orange" 또는 "bored" 값과 일치합니다. 필터 로직을 "disabled"로 설정하면 필드별 필터링이 완전히 비활성화됩니다.

### 그룹화

UI 내에서 관련 사용자 정의 필드를 각각에 동일한 그룹 이름을 할당하여 함께 그룹화할 수 있습니다. 객체 유형에 대해 하나 이상의 사용자 정의 필드에 그룹이 정의되면 객체 보기 아래의 사용자 정의 필드 패널 내에서 그룹 제목 아래에 표시됩니다. 동일한 그룹 이름을 가진 모든 사용자 정의 필드는 해당 제목 아래에 표시됩니다. (그룹 이름은 정확히 일치해야 합니다. 그렇지 않으면 각각 별도의 제목으로 표시됩니다.)

이 매개변수는 사용자 정의 필드 데이터의 API 표현에 영향을 미치지 않습니다.

### 표시 및 편집

사용자 정의 필드를 만들 때 사용자는 NetBox 사용자 인터페이스 내에서 표시되고 편집될 수 있는 조건을 제어할 수 있습니다. 객체에 사용자 정의 필드 표시를 제어하기 위해 다음 선택 항목을 사용할 수 있습니다:

* **Always** (기본값): 객체를 볼 때 사용자 정의 필드가 포함됩니다.
* **If Set**: 객체에 대해 값이 정의된 경우에만 사용자 정의 필드가 포함됩니다.
* **Hidden**: 사용자 정의 필드는 UI 내에서 표시되지 않습니다. 이 옵션은 인간 사용자용이 아닌 필드에 권장됩니다.

또한 NetBox UI 내에서 사용자 정의 필드 값을 변경할 수 있는지 여부를 제어하기 위해 다음 옵션을 사용할 수 있습니다:

* **Yes** (기본값): 객체를 편집할 때 사용자 정의 필드의 값을 수정할 수 있습니다.
* **No**: 객체를 편집할 때 참조용으로 사용자 정의 필드가 표시되지만 값을 수정할 수 없습니다.
* **Hidden**: 객체를 편집할 때 사용자 정의 필드가 표시되지 않습니다.

이 설정은 REST 또는 GraphQL API에 영향을 미치지 않습니다: 사용자 정의 필드 데이터는 항상 두 API를 통해 사용할 수 있습니다.

### 유효성 검사

NetBox는 사용자 정의 필드 값에 대해 제한된 사용자 정의 유효성 검사를 지원합니다. 다음은 각 필드 유형에 대해 적용되는 유효성 검사 유형입니다:

* Text: 정규 표현식(선택 사항)
* Integer: 최소 및/또는 최대값(선택 사항)
* Selection: 규정된 선택 항목 중 하나와 정확히 일치해야 함

### 사용자 정의 선택 필드

각 사용자 정의 선택 필드는 최소 두 개의 선택 항목이 포함된 [선택 세트](../models/extras/customfieldchoiceset.md)를 지정해야 합니다. 이들은 쉼표로 구분된 목록으로 지정됩니다.

선택 필드에 기본값이 지정된 경우 제공된 선택 항목 중 하나와 정확히 일치해야 합니다. 다중 선택 필드의 값은 하나의 값만 선택하더라도 항상 목록을 반환합니다.

### 사용자 정의 객체 필드

객체 또는 다중 객체 사용자 정의 필드를 사용하여 특정 NetBox 객체를 사용자 정의 필드의 "값"으로 참조할 수 있습니다. 이러한 사용자 정의 필드는 사용자 정의 필드 인스턴스가 가리키는 객체 유형을 결정하는 `object_type`을 정의해야 합니다.

기본적으로 객체 선택 필드는 해당 유형의 모든 객체를 드롭다운에서 선택할 수 있도록 합니다. Related Object Filter 필드에 `query_params` 딕셔너리를 JSON 값으로 제공하여 특정 값을 가진 객체만 표시하도록 선택 항목 목록을 필터링할 수 있습니다. `query_params`에 대한 자세한 정보는 [여기](./custom-scripts.md#objectvar)에서 찾을 수 있습니다.

## 템플릿의 사용자 정의 필드

내보내기 템플릿 및 웹훅과 같은 NetBox 내의 여러 기능은 Jinja2 템플릿을 활용합니다. 편의를 위해 사용자 정의 필드 할당을 지원하는 객체는 `cf` 속성을 통해 사용자 정의 필드 데이터를 노출합니다. 이것은 실제 필드(`custom_field_data`)를 통해 사용자 정의 필드 데이터에 접근하는 것보다 약간 더 깔끔합니다.

예를 들어, Site 모델에 `foo123`이라는 사용자 정의 필드는 인스턴스에서 `{{ site.cf.foo123 }}`로 접근할 수 있습니다.

## 사용자 정의 필드와 REST API

REST API를 통해 객체를 검색할 때 모든 사용자 정의 데이터는 `custom_fields` 속성 내에 포함됩니다. 예를 들어, 아래는 두 개의 사용자 정의 필드가 정의된 사이트의 부분 출력입니다:

```json
{
    "id": 123,
    "url": "http://localhost:8000/api/dcim/sites/123/",
    "name": "Raleigh 42",
    ...
    "custom_fields": {
        "deployed": "2018-06-19",
        "site_code": "US-NC-RAL42"
    },
    ...
```

이러한 값을 설정하거나 변경하려면 중첩된 JSON 데이터를 포함하면 됩니다. 예:

```json
{
    "name": "New Site",
    "slug": "new-site",
    "custom_fields": {
        "deployed": "2019-03-24"
    }
}
```
