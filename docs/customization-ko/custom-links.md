# 사용자 정의 링크

사용자 정의 링크를 사용하면 NetBox 객체 보기 내에서 외부 콘텐츠에 대한 임의의 하이퍼링크를 표시할 수 있습니다. 이는 NetBox 외부 시스템의 관련 레코드를 상호 참조하는 데 유용합니다. 예를 들어, 네트워크 모니터링 시스템(NMS)의 현재 장비에 연결되는 장비 보기에 사용자 정의 링크를 만들 수 있습니다.

사용자 정의 링크는 Customization > Custom Links로 이동하여 생성됩니다. 각 링크는 특정 NetBox 객체 유형(사이트, 장비, 프리픽스 등)과 연결되며 관련 보기에 표시됩니다. 각 링크에는 표시 텍스트와 URL이 있으며, 보고 있는 NetBox 항목의 데이터는 `object` 변수를 통해 [Jinja 템플릿 코드](https://jinja.palletsprojects.com/en/stable/)를 사용하여 링크에 포함할 수 있고, 사용자 정의 필드는 `object.cf`를 통해 포함할 수 있습니다.

예를 들어, 다음과 같은 링크를 정의할 수 있습니다:

* 텍스트: `View NMS`
* URL: `https://nms.example.com/nodes/?name={{ object.name }}`

Router4라는 장비를 볼 때 이 링크는 다음과 같이 렌더링됩니다:

```no-highlight
<a href="https://nms.example.com/nodes/?name=Router4">View NMS</a>
```

사용자 정의 링크는 페이지 오른쪽 상단 모서리에 버튼으로 표시됩니다. 숫자 가중치를 사용하여 링크 순서에 영향을 줄 수 있으며, 각 링크는 개별적으로 활성화하거나 비활성화할 수 있습니다.

!!! warning
    사용자 정의 링크는 사용자가 만든 코드에 의존하여 임의의 HTML 출력을 생성하므로 위험할 수 있습니다. 신뢰할 수 있는 사용자에게만 사용자 정의 링크를 만들거나 수정할 수 있는 권한을 부여하세요.

## 컨텍스트 데이터

사용자 정의 링크의 텍스트 또는 URL을 렌더링할 때 템플릿 내에서 다음 컨텍스트 데이터를 사용할 수 있습니다.

| 변수 | 설명 |
|------|------|
| `object` | 표시되는 NetBox 객체 |
| `debug` | 디버깅이 활성화되었는지 여부를 나타내는 부울 |
| `request` | 현재 WSGI 요청 |
| `user` | 현재 사용자(인증된 경우) |
| `perms` | 사용자에게 할당된 [권한](https://docs.djangoproject.com/en/stable/topics/auth/default/#permissions) |

위에 나열된 대부분의 컨텍스트 변수는 일관된 속성을 가지지만, 객체는 링크가 렌더링될 때 보고 있는 특정 객체의 인스턴스입니다. 다른 모델에는 다른 필드와 속성이 있으므로 특정 객체 유형에 대한 템플릿에서 사용할 수 있는 속성을 결정하기 위해 약간의 조사가 필요할 수 있습니다.

객체의 REST API 표현을 확인하는 것은 일반적으로 사용 가능한 속성을 결정하는 편리한 방법입니다. 포괄적인 목록을 보려면 NetBox 소스 코드를 직접 참조할 수도 있습니다.

## 조건부 렌더링

비어 있지 않은 텍스트로 렌더링되는 링크만 페이지에 포함됩니다. 조건부 Jinja2 로직을 사용하여 링크가 렌더링되는 조건을 제어할 수 있습니다.

예를 들어, 활성 장비에 대해서만 링크를 표시하려면 링크 텍스트를 다음과 같이 설정할 수 있습니다.

```jinja2
{% if object.status == 'active' %}View NMS{% endif %}
```

"active" 이외의 상태를 가진 장비를 볼 때 링크가 표시되지 않습니다.

또 다른 예로, 특정 제조업체에 속한 장비만 표시하려면 다음과 같이 할 수 있습니다:

```jinja2
{% if object.device_type.manufacturer.name == 'Cisco' %}View NMS{% endif %}
```

제조업체 이름이 "Cisco"인 장비를 볼 때만 링크가 표시됩니다.

## 링크 그룹

그룹 이름을 지정하여 링크를 그룹으로 구성할 수 있습니다. 동일한 그룹 이름을 가진 링크는 그룹 이름을 표시하는 단일 버튼 아래에 드롭다운 메뉴로 렌더링됩니다.

## 테이블 열

사용자 정의 링크는 테이블 구성 양식에서 원하는 링크를 선택하여 객체 테이블에도 포함할 수 있습니다. 표시될 때 각 링크는 해당 객체에 대한 하이퍼링크로 렌더링됩니다. 내보낼 때(예: CSV 데이터로) 각 링크는 URL만 렌더링합니다.
